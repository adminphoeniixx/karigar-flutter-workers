# India city reference

Source: https://github.com/dr5hn/countries-states-cities-database
Export: `json/countries+states+cities.json`, retrieved 2026-09-30.
License: Open Database License (ODbL) 1.0; full terms in
`assets/data/LOCATION_DATA_LICENSE.txt`.

`assets/data/india_cities.json` is a derivative India-only subset, distributed
under ODbL 1.0. It retains state/city names, removes name diacritics for search,
deduplicates cities within each state and sorts them. No coordinates are bundled.
It includes all 36 states/union territories, and supplements server results;
it is not a complete list of every village or locality. Edit Profile uses state-dependent dropdowns; saved legacy cities are retained.
Registration also accepts manual input for missing places. The derivative JSON is bundled as a readable
asset with the application. Retain this attribution and license when distributing.
